# 界面

当前视觉依据是 OpenDesign 的手机稿。产品是 Flutter 应用，按这套视觉实现，不另起一套网页。

## 语气

Proclaim Wall 的公告墙。黑白灰，细线，直角小圆角。标题用同一套无衬线，靠字号和字重拉开，不靠颜色。强调色是当前主题的前景色：深色里是白，浅色里是近黑。危险操作才用红。

没有记下选择时，深浅色跟随系统，语言跟随系统并只在中文和英文里匹配，对不上时用中文。选过之后，`proclan.theme` 是 `dark` 或 `light`，`proclan.locale` 是 `zh` 或 `en`。设置里没有回到跟随系统的开关。

浅色把背景换成 `#f4f4f5`，卡片换成白，正文换成 `#09090b`，线换成 `#e4e4e7`。强调变成 `#09090b`，上面的字是白。危险字是 `#b91c1c`。

圆角：按钮和输入 4，卡片和头像 8。动效 `cubic-bezier(.2, 0, 0, 1)`。

字体是 PingFang SC，后面跟着 Inter、DM Sans 和系统中文。稿里的西文优先是 Inter，应用没有打包这套字体，所以界面指定 PingFang SC。

栏宽：信息流 960，文章和设置 820。左右边距是屏宽的 4%，夹在 16 和 40 之间。

## 登录

宽屏左右分栏，左栏略宽。左栏是海边照片，两层压暗，标题「把信息流，还给自己。」右栏卡片垂直居中，从标题开始。登录说明是「登录后，只看属于你的日报。」链接是「创建账号」。注册用「返回登录」回到登录。

登录和注册都是用户名和密码。注册页写明「这是登录名，不能和别人重复，之后可以修改。」窄屏改成上图下文。错误前面有一个「!」圆标。这一屏没有语言切换。设置里还没选过时，语言跟随系统。

## 信息流

顶栏是侧栏按钮、未读，右侧是日期：月、日和星期。侧栏按钮打开侧栏。侧栏先是社区，然后是 Bot。底部是用户名和设置，设置从底部弹出设置卡。方标是用户名首字，拉丁字母大写。用户名还没载入时，方标留空。

从关注的 bot 复制来的卡片，在信息流里用来源处显示 bot 名和主人的用户名。自己的卡片仍显示发布来源。

未读按钮打开「只看未读」。没有未读时按钮停用，文案是「全部已读」。已经在只看未读时，这个按钮让开，下面的筛选条负责退出。

没有分类条。卡片是描边矩形：阅读时间、标题、两行摘要、来源和时间。有图时缩略图在右侧，文章页的大图仍在摘要上面。按天分组，今天展开，更早的默认收起。应用不按分类筛选，也不在卡片上标分类。

## 文章

顶栏吸住，左侧返回，中间是时间，右侧是分享。分享交给系统的是标题、摘要、去掉单独一行图表标记后的正文、来源、来源链接和视频地址。代码块里的图表标记保留。不含图表数据。对方拿到的是这段文字，不是卡片链接。底边是阅读进度。正文放在描边卡片里，顺序是大图、视频、标题、摘要、正文、正文没有安放的图表、标签、来源和 bot 署名。直接的视频文件在大图和标题之间按 16:9 播放。网页观看地址在应用外打开。单独一行 `[[chart:N]]` 把对应的图表放在段落之间。同一张图只画一次。代码块里的标记仍是文字。颜色来自主题。宽屏正文 17 像素，二级标题 22 像素、字重 500。标记未读是描边按钮。删除是危险色描边，确认框的确认按钮是红底白字。关注后复制来的卡片保留这两个按钮。从社区打开的别人的原卡片，这两个按钮都不出现。复制来的卡片同时显示 bot 名和主人的用户名。大图按 8 像素圆角裁切。

## 设置

信息流的侧栏直接进入 Bot。设置从底部弹出一张卡。卡里是外观、语言、只看未读、缓存和自动同步，然后是账号与安全。退出登录在这张卡上。卡里没有 Bot。深色和浅色立刻生效。账号与安全打开自己的一页，返回回到信息流。返回按钮的提示是「返回」。

这台设备上的卡片缓存和已读状态属于当前登录的账号。同一个设备上的另一个账号只能看到自己的卡片。

账号页是用户名输入框和说明：这是登录名，不能和别人重复，之后可以修改。保存是右对齐的实心按钮。保存后会话还在。新名字就是下一次的登录名。

修改密码是单独一页：当前密码，然后是新密码。成功后退出登录，回到登录页。bot token 保持不变。

Bot 页先列出自己的名字，再按主人分组列出关注的 bot。点自己的名字进入详情：基本信息里是首次出现和功能介绍，下面是服务端还留着的全部推送。同一页可以把这个 bot 分享到本服务器的社区。第一次分享生成 8 位短码。页上显示是否已分享、短码、点赞数和关注数。停止分享需要确认。点一张进入卡片详情，返回只退回 Bot 详情。可以删除这个名字。确认后只从列表去掉，分享也停下来。卡片还在，短码也还在。下次同一名称推送会再出现，分享开关是关的，要再分享一次才恢复。点一个关注的 bot，看到复制给你的卡片。已下线的留在分组里并标明。token 下方只有一个按钮，用来复制 MCP 安装提示词。提示词不点名某个客户端，文案跟随界面语言。复制时带上当前 bot token 和本应用的服务地址。提示词要求每次写卡片先读 `submit_cards` 的 inputSchema，按当前 schema 填，不要把字段写进提示词。

信息流滚过一屏后，右下角可以回到顶部。

## 社区

社区是这一台服务器上的一页。上面是搜索，下面两段：点赞榜、关注榜。每个榜列出 50 个正在分享的 bot，包括人数是 0 的。人数高的在前。人数相同，第一次分享更早的在前。一行是名次、首字、bot 名、主人与介绍，以及这一榜的人数。搜索替换这两个榜。完整短码即使 bot 已下线也排在第一条。其他词匹配 bot 名或主人用户名。点一行打开这个 bot，看到介绍、点赞、差评、关注人数、短码，以及关注、点赞、差评，还有服务端还留着的最新一张卡片。这三个是靠右的图标：眼睛、拇指向上、拇指向下。关注亮起是蓝色，点赞亮起是红色，差评亮起用前景色。bot 已下线时这三个停用，只有已经关注的人可以取消关注。主人看自己的 bot 时没有这三个按钮。阅读那张最新卡片时没有删除，也没有标记未读。已经关注的人可以打开复制给自己的全部卡片。没有网页链接。

## 不改

启动图标是黑底、银色字母 P。分类请求值、已读存在本机、登录和 bot token 的分工，都不跟着这张稿变。
