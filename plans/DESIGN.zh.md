# 界面

当前视觉依据是 2026-10-26 的编辑稿。

稿是单文件 HTML。产品是 Flutter 应用，按这套视觉实现，不另起一套网页。

## 语气

Proclaim Wall 的公告墙。黑白灰，细线，直角小圆角。标题用同一套无衬线，靠字号和字重拉开，不靠颜色。强调色是当前主题的前景色：深色里是白，浅色里是近黑。危险操作才用红。

没有记下选择时，深浅色跟随系统，语言跟随系统并只在中文和英文里匹配，对不上时用中文。选过之后，`proclan.theme` 是 `dark` 或 `light`，`proclan.locale` 是 `zh` 或 `en`。设置里没有回到跟随系统的开关。

浅色把背景换成 `#f4f4f5`，卡片换成白，正文换成 `#09090b`，线换成 `#e4e4e7`。强调变成 `#09090b`，上面的字是白。危险字是 `#b91c1c`。

圆角：按钮和输入 4，卡片和头像 8。动效 `cubic-bezier(.2, 0, 0, 1)`。

字体是 PingFang SC，后面跟着 Inter、DM Sans 和系统中文。稿里的西文优先是 Inter，应用没有打包这套字体，所以界面指定 PingFang SC。

栏宽：信息流 960，文章和设置 820。左右边距是屏宽的 4%，夹在 16 和 40 之间。

## 登录

宽屏左右分栏，左栏略宽。左栏是海边照片，两层压暗，标题「把信息流，还给自己。」右栏卡片垂直居中，从标题开始。登录说明是「登录后，只看属于你的日报。」链接是「创建账号」。注册用「返回登录」回到登录。

登录和注册都是用户名和密码。注册页写明「这是登录名，不能和别人重复，之后可以修改。」窄屏改成上图下文。错误前面有一个「!」圆标。

## 信息流

顶栏是日期：大号日、月份和星期、这一期的条数。右边是未读、刷新、用户头像方标（打开设置）。方标是用户名首字，拉丁字母大写，和「我的」里的头像相同。用户名还没载入时，顶栏方标留空。

未读按钮打开「只看未读」。没有未读时按钮停用，文案是「全部已读」。已经在只看未读时，这个按钮让开，下面的筛选条负责退出。

分类是一排描边小块，选中的填上强调色。卡片是描边矩形：分类、阅读时间、标题、两行摘要、来源和时间。有图时缩略图在右侧，文章页的大图仍在摘要上面。按天分组，今天展开，更早的默认收起。

## 文章

顶栏吸住，左侧返回，中间是分类和时间，底边是阅读进度。正文放在描边卡片里：图、标题、摘要、正文、标签、来源。标记未读是描边按钮。删除是危险色描边，确认框的确认按钮是红底白字。大图按 8 像素圆角裁切。正文渲染 Markdown。

## 设置

从信息流推入，先到「我的」。资料卡是方头像、名字和「编辑资料」。下面三格是 bot 数、未读数、缓存时长。「阅读」进入偏好设置、账号与安全、Bot 与接入。「更多」是隐私和退出登录。子页的返回回到「我的」，「我的」的返回回到信息流。返回按钮的提示是「返回」。

偏好里是外观、语言、只看未读、缓存和自动同步。深色和浅色立刻生效。

账号页是用户名输入框和说明：这是登录名，不能和别人重复，之后可以修改。保存是右对齐的实心按钮。保存后会话还在。新名字就是下一次的登录名。

修改密码是单独一页：当前密码，然后是新密码。成功后退出登录，回到登录页。bot token 保持不变。

Bot 页列出名字。点一个名字进入详情：基本信息里是首次出现和功能介绍，下面是服务端还留着的全部推送。点一张进入卡片详情，返回只退回 Bot 详情。可以删除这个名字。确认后只从列表去掉，卡片还在，下次同一名称推送会再出现。token 下方只有一个按钮，用来复制 MCP 安装提示词。提示词不点名某个客户端，文案跟随界面语言。复制时带上当前 bot token 和本应用的服务地址。提示词要求每次写卡片先读 `submit_cards` 的 inputSchema，按当前 schema 填，不要把字段写进提示词。

隐私页说明数据留在自己的服务和这台设备上。信息流滚过一屏后，右下角可以回到顶部。

## 不改

启动图标是黑底、银色字母 P。分类请求值、已读存在本机、登录和 bot token 的分工，都不跟着这张稿变。
